# SpendIQ

**Smart expense tracking with AI-powered transaction entry.**

SpendIQ is a modern **AI-integrated expense tracker** built with the **MERN Stack**. It helps users manage income and expenses, monitor transactions, create budgets, and understand their financial activity through an interactive dashboard.

The AI feature makes adding transactions faster — simply describe what you spent or received, and SpendIQ automatically identifies the **amount, transaction type, date, and category**.

### 🤖 AI Transaction Assistant

SpendIQ includes an AI-powered transaction assistant.

Instead of manually filling a form, users can write:

> `I spent ₹500 on dinner yesterday`

The AI automatically identifies:

```text
Type: Expense
Amount: ₹500
Category: Food
Date: Yesterday
Description: Dinner
```

The extracted information is shown to the user for confirmation before the transaction is saved.
